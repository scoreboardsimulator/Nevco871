Quick start

Start up

  1. At the prompt, press No twice, then type 8 7 1.
  2. Answer Yes or No to the penalty time out question. The board turns on.

Set 8 minutes, period 1

  1. Set Time
  2. 0 8 then Yes
  3. At PERIOD, press 1
  4. Flip the hand-held rocker to ON to start the clock and to OFF to stop it. While the hand-held is plugged in (it starts that way) the Time On and Time Off keys are locked. To use the keys, press Unplug, then power the control off and on.
  5. Stopping the clock silences the auto horn.

Common jobs

  • Score: Home Score then a digit adds that many. To correct, Set Home Score, type the total, Yes.
  • Penalty: Set Home Penalty, time, Yes, player number, Yes.
  • Review penalties with Home Penalty. While one shows, use Insert, Edit or Clear.
  • Time out: Time Out Timer Start then 0 to 9. Clear cancels it.
  • Options scrolls the current settings. Set Options changes them.
  • Set Horn turns the auto horn on or off.
  • Chronometer shows time of day. Set Chronometer enables it for the scoreboard and sets the clock.
  • Set Misc Shot Time sets the shot clock length (turn on Shot clocks in Settings first). Misc Shot Time restarts it.
  • Aux timer, segment timer, clock direction and bookmarks are all in the Set Options questions.
  • Hand-held: use the Unplug button at the top to unplug it from the control.
  • Reload the page to simulate a power failure, then answer Yes to start where turned off last.
